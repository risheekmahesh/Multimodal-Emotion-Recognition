# Dataset

This project uses the **RAVDESS (Ryerson Audio-Visual Database of Emotional Speech and Song)** dataset.

The dataset contains emotional speech recordings from **24 actors** across **8 emotion classes**:

| Code | Emotion |
|------|---------|
| 01 | Neutral |
| 02 | Calm |
| 03 | Happy |
| 04 | Sad |
| 05 | Angry |
| 06 | Fearful |
| 07 | Disgust |
| 08 | Surprised |

The dataset is not included in this repository because of its large size.
## Dataset Source

The RAVDESS dataset used in this project was obtained from Kaggle:

https://www.kaggle.com/datasets/uwrfkaggler/ravdess-emotional-speech-audio
